# Element NAV HTML

Proyecto de plataforma para la visualización de eventos de tecnología desarrollado con **HTML5** semántico. Implementa navegación mediante enlaces internos y organiza eventos próximos y pasados utilizando etiquetas adecuadas para fechas, imágenes y contenedores independientes.

---

## 🚀 Características

- **Navegación Interna:** Uso del elemento `<nav>` con hipervínculos hacia secciones específicas de la misma página (`#upcoming-events` y `#past-events`).
- **Estructura Semántica:** División modular con `<header>`, `<main>`, `<section>` y `<article>`.
- **Manejo de Fechas:** Implementación de la etiqueta `<time>` con el atributo `datetime` para representar fechas legibles por buscadores y navegadores.
- **Soporte Multimedia:** Inclusión de imágenes ilustrativas con texto alternativo (`alt`) para mayor accesibilidad.
